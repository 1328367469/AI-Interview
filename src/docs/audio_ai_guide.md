# 专业语音及AI大模型服务申请指南

为了让您的面经和系统在国内能够稳定、流畅并且高度拟真地运行，我们为您整理了以下专业服务提供商，您可以直接注册个人开发者免费使用或领取海量测试额度。

## 1. 核心大脑：DeepSeek (已接入)
DeepSeek 是目前国内性价比最高，且代码与逻辑能力顶级的模型。
* **适用场景**：JD分析、简历匹配、模拟面试核心QA、生成分析报告。
* **申请地址**：[DeepSeek 开放平台](https://platform.deepseek.com/)
* **费用**：注册赠送体验额度，后续使用极度便宜（1元可用几百万Token）。

## 2. 语音识别 (STT / 录音转文字) 与 语音合成 (TTS)

针对您的需求：**不需要长按说话、全双工、机器人说话时关闭收音**，我们需要强大的 ASR + VAD（静音检测），以及高度拟人的跨模态或专业 TTS API。

由于国外 Groq, OpenAI 访问在国内受限，推荐以下完全合规且免费/低价的国内大厂方案：

### 推荐方案一：火山引擎 (字节跳动 - 豆包) - 综合最佳
抖音同款语音与大模型技术，发音极其自然（有很多极其逼真的面试官音色），个人可申请。
* **申请地址**：[火山引擎 - 语音技术](https://www.volcengine.com/product/voice-technology)
* **包含服务**：
  * **实时语音识别 (流式 ASR)**：极速识别，解决连续说话的识别需求。
  * **语音合成 (TTS)**：推荐使用“豆包拟人音色”模拟各个风格的面试官。
* **费用**：实名认证后赠送50元额度 或 3个月免费调用额度，完全足够个人开发者使用。

### 推荐方案二：阿里云 (DashScope / 百炼平台) - 接入最快
阿里通义千问旗下的语音模型（CosyVoice）是目前开源界最强且拟人度最高的语音合成技术。
* **申请地址**：[阿里云百炼平台](https://bailian.console.aliyun.com/)
* **包含服务**：
  * CosyVoice 语音合成 (超高拟人度，带呼吸声、情绪起伏)。
  * SenseVoice 语音识别 (支持中英文混写，方言口音，识别极快)。
* **费用**：开通即送每个模型几十万到上百万的免费 Token 或调用频次。

## 3. 面试情绪检测与人脸分析 (Web端实现方案)
面试完的情绪分析不需要调用昂贵的后端 API。可以在前端直接运行轻量级模型。
* **实现方案**：**face-api.js** 
* **特点**：完全在本地浏览器（电脑或手机）离线运行，免费，零延迟。可以实时抓取摄像头的帧并检测用户的表情（开心、紧张、平淡）以生成最终评估。

## 本次迭代实施计划 (Step by Step)

我们将按照以下步骤为您落地第一版“专业级语音面试系统”：

1. **先实现前端状态机流转 (UI与流转逻辑)**：基于 Web Speech API（浏览器原生免费且不需注册的长录音方案）先实现“点击开始面试 -> 无限循环收音 -> 发送给 DeepSeek -> 收到回复 TTS 播放 -> 播放时暂停收音”。这一步将打通产品逻辑。
2. **前后端 TTS/STT 接口预留**：编写一个支持切换到阿里云或火山引擎的 Adapter（适配器），为您后续填入秘钥直接起飞留好接口。
3. **情绪识别接入**：在面试页面接入 `face-api.js`，每隔几秒截取一帧，记录情绪。
4. **生成深度报告**：最后使用 DeepSeek 根据整个对话记录 + 情绪统计，生成详细的《面试诊断报告》。
